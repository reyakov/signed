### Milestone 1: release the first out-of-box experience version
Alpha version has been released, I'm working toward the first stable release for the desktop version, which will include a fully git workflow, repository management and collaboration. The stable version will maximum compatible with other nostr git (grasp) client

### Milestone 2: release the web version and mobile apps
Release the web for browsing and repository management, full git workflow and collaboration still require the desktop app. About the mobile apps, it not only a hub for repositories but also control the agents which will be add later

### Milestone 3: social coding and web of trust
Implement social layer, each repository can become a community (NIP-29), sharing patch snippets or napplet (NIP-5D) like sharing posts. The web of trust layer will help me user focus on works and support from their circle, provide more information to help user make decision, prevent bad actor can affect the software or supply chain.

### Milestone 4: agent collaboration and workspace
Support users to plug their coding agents to resolve or review issues, patches, and pull requests. Workspace is a specific environment, allowing users to try new ideas, test a patch in a parallel branch without affecting the main tree.

### Milestone 5: private repository and team collaboration
Support multiple teammates, channel and communication. Automate turning the discussion into plans and pull requests without hopping between multiple tools.
